# Clear the rphylopic cache

Clears both the HTTP response cache
[`httpcache::clearCache()`](https://enpiar.com/r/httpcache/reference/cache-management.html)
and the parsed image object cache used by
[`get_phylopic()`](https://rphylopic.palaeoverse.org/reference/get_phylopic.md).

## Usage

``` r
clear_phylopic_cache()
```

## Value

No return value, called for side effects.
